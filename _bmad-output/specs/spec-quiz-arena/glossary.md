# Glossary

| Term | Meaning |
| --- | --- |
| Minnal (മിന്നൽ) | The product. The word means "lightning" in Malayalam |
| Kerala PSC | Kerala Public Service Commission, which recruits for Kerala state government posts through competitive exams |
| Aspirant | A candidate preparing for PSC exams |
| 10th-level | PSC exams whose minimum qualification is passing 10th standard, such as LGS and LDC. The primary launch segment |
| LGS | Last Grade Servant, a PSC post |
| LDC | Lower Division Clerk, a PSC post |
| Degree-level | PSC exams that require a graduate degree. The secondary segment |
| PYQ | Previous-year question, a real question from an earlier PSC exam |
| Batch battle | A coaching center's informal WhatsApp quiz: the teacher posts a question and students race to answer first |
| Coaching center | A private PSC coaching institute. The launch distribution channel and the future B2B customer |
| Bot | A computer opponent in Quick Match or Topic Duel, always shown with a badge |
| Rating track | One of the three independent ELO ratings: Quick Match, Topic Duel, Battle Room |
| Answer window | The 15 s during which a live question accepts answers |
| Custom topic | A player's private question set, imported as JSON |
| DLT | India's Distributed Ledger Technology registration, which TRAI requires for anyone sending commercial or OTP SMS |
| DPDP Act | India's Digital Personal Data Protection Act, 2023 |
