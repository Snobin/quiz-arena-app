## Findings

Every deferred-work claim below was re-checked against current `main` before routing.

### F1. Rate-limit token is spent before validation (3.3 and 3.5), the same ordering twice
- Source: `AdminUploadController.java:52`, `QuestionReportController.java:65` both call `limiter.tryAcquire` first. Deferred-work entries for 3.3 and 3.5 flag the same thing.
- Effect: malformed uploads and invalid, 404 and 409 reports drain the 10/hour and 5-report budgets.
- Disposition: **fix now**, as one decision for both. Prevention: add "limiter position relative to validation" to the story template, as the same ordering was written twice.

### F2. Valkey outage becomes an unshaped 500, fail-open vs fail-closed undefined (3.3)
- Source: `ValkeyRateLimiter.tryAcquire` (line 65) throws; no admin handler maps it. Production selection by `minnal.ratelimit.store` has no test.
- Disposition: **fix now** (decide the policy, add a Problem Details response, add the `ApplicationContextRunner` test). Owner decision needed on the policy.

### F3. Publish and discard ignore `rowVersion` (3.4)
- Source: `AdminDraftController` has no `rowVersion` handling. A reviewer can publish content another admin edited after the queue loaded.
- Disposition: **defer** while there is one admin. Becomes fix-now when a second admin is added.

### F4. Editor tells two 409s apart by message text (3.2)
- Source: `QuestionEditor.tsx` 409 branch; no stable `reason` property found.
- Disposition: **fix now**, small: add a `reason` to the Problem Details and branch on it.

### F5. Save succeeds but refresh fails, editor shows "Could not save" on stale state (3.2)
- Source: `QuestionEditor.tsx` submit wraps save and refresh in one try block.
- Disposition: **fix now**, small (split the try blocks).

### F6. Size growth: `QuestionEditor.tsx` is 841 lines, `QuestionsPage.tsx` 405
- Source: `git_evidence.py` plus `wc -l`. `QuestionEditor.tsx` was touched by 3 stories (3.2, 3.4, 3.6) and is the largest file under `web/src/admin`. `ReportsPage.tsx` (393) and `adminI18n.ts` (355) are next.
- Disposition: **defer** until Epic 6 reuses the editor; split then. Not a defect yet, a candidate.

### F7. Reports page has no paging past 100 groups (3.6)
- Source: `fetchReports` requests page 0, size 100; groups beyond that cannot be viewed or dismissed.
- Disposition: **defer**. Low risk at launch volume.

### F8. Publish and report resolution rollback is not pinned by a test (3.6)
- Source: `aFailedPublishLeavesReportsOpen` fails on validation before `publishDraft`, so the same-transaction rule in `AdminDraftService.publishInTransaction` is untested.
- Disposition: **fix now**, as a fault-injection test.

### F9. Smaller deferred items, all verified still open
- `AdminMappingArchitectureTest` does not assert every admin method calls `requireAdmin` (3.1). Disposition: **fix now**, cheap and security-relevant.
- `/admin` has no `noindex`; `web/index.html` has none. Disposition: **fix now**, trivial.
- `session.isAdmin()` not reactive after a token refresh drops ADMIN (3.1). Disposition: **defer**, API still returns 403.
- Router popstate handling misbehaves on Forward and repeated blocked Back (3.2). Disposition: **defer**.
- Restoring a draft-only question leaves it with only a DISCARDED version (3.2). Disposition: **owner decision**.
- Mid-match reload drops `questionSource`, so the live-reveal report link is hidden; a soft-deleted question's published version can still be reported (3.5). The reload part overlaps the recent SNAPSHOT fix (PR #74) and the Epic 5 retro item; **defer** and fold into that item.
- Tab-close `keepalive` commit drops an action when the token is missing or expired (3.4). Disposition: **defer**.
- `updatedAt` ignores soft delete and discard (3.1). Disposition: **defer**; settle with F9 editor work.
